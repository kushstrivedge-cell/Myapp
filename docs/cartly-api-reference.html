1. Conventions

Base URL: configured by the client, ending in /api/v1. Successful JSON responses normally use { success: true, data: ... }. Validation and application failures are handled by the central error middleware.
Access labelRequirement
PublicNo access token.
Optional / guestBearer token when signed in, otherwise x-guest-cart-token.
UserAuthorization: Bearer <accessToken>.
AdminBearer token for a user with role ADMIN.

Common statuses: 200 success, 201 created, 204 success without a body, 400 validation, 401 unauthenticated, 403 forbidden, 404 missing resource, 409 conflict, 429 rate limited, and 500 server error.

2. System and authentication

GET/api/healthPublic

Service health probe. Alias: GET /api/v1/health.

POST/auth/registerPublic · OTP limited

Create a customer and send email verification OTP.

Body: name 2–80, valid email, 10-digit phone, password 8–128.

POST/auth/verify-emailPublic

Verify registration. Body: email, six-digit code.

POST/auth/resend-email-otpPublic · OTP limited

Resend verification OTP. Body: email.

POST/auth/loginPublic

Authenticate and return access/refresh tokens. Body: email, password.

POST/auth/refreshPublic

Rotate authentication using refreshToken.

POST/auth/logoutPublic

Revoke refreshToken. Returns 204.

POST/auth/forgot-passwordPublic · OTP limited

Send password-reset OTP. Body: email.

POST/auth/reset-passwordPublic

Body: email, six-digit code, newPassword 8–128.

GET/auth/meUser

Return the currently authenticated user. Used by mobile and admin clients.

Query: q, category, minPrice, maxPrice, minRating, inStock, onSale, sort (popular/rating/price_asc/price_desc/newest), page, limit ≤ 50.

7. Payments and Razorpay Test Mode

POST/payments/initializeUser

Create/reuse Razorpay order. Body: orderId, idempotencyKey.

POST/payments/verifyUser

Verify checkout signature. Body: local orderId, razorpay_order_id, razorpay_payment_id, 64-hex razorpay_signature.

POST/payments/failedUser

Record checkout failure. Body: orderId; optional Razorpay order ID, code and description.

POST/payments/orders/:orderId/refundsAdmin

Request refund. Body: optional amount, required reason, unique idempotencyKey.

POST/api/v1/payments/webhookRazorpay signature

Raw JSON webhook receiver. Validates x-razorpay-signature using RAZORPAY_WEBHOOK_SECRET.

External API calls made by the backend

Provider endpointPurpose
POST https://api.razorpay.com/v1/ordersCreate test-mode payment orders.
POST https://api.razorpay.com/v1/payments/:paymentId/refundCreate refunds with Razorpay Basic authentication and idempotency protection in Cartly.
Security: only rzp_test_ keys are accepted. Key secret and webhook secret stay on the backend. Raw card numbers and CVV are not collected by Cartly.

9. Administration API

Every route below requires an authenticated ADMIN.

GET/admin/dashboardAdmin

KPIs, charts, recent activity and stock alerts. Query: optional ISO from, to.

Categories

GET /admin/categories list · POST /admin/categories create (name, slug, parentId?) · PATCH /admin/categories/:id edit · DELETE /admin/categories/:id delete empty category.

Products and stock

GET /admin/products list with category, variants and images · POST /admin/products create product with at least one variant · PATCH /admin/products/:id edit product/images · DELETE /admin/products/:id soft-disable · PATCH /admin/variants/:id change price, old price or stock.

Product: name, slug, description, categoryId, active, variants[], images[]. Variant: sku, colour?, size?, price, oldPrice?, stock. Image: url, alt?, position.

Orders and returns

GET /admin/orders · PATCH /admin/orders/:id/status · GET /admin/returns · PATCH /admin/returns/:id/review · PATCH /admin/returns/:id/status · POST /admin/returns/:id/complete.

Coupons

GET /admin/coupons · POST /admin/coupons · PATCH /admin/coupons/:id · DELETE /admin/coupons/:id. Fields: code, percentOff?, amountOff?, minimumCart?, active, startsAt?, expiresAt?.

Customers, reviews and reports

GET /admin/customers · PATCH /admin/customers/:id (active?, role?) · GET /admin/reviews · DELETE /admin/reviews/:id · GET /admin/reports/sales?from=&to=.
